# Data Privacy & Governance Compliance Audit Portfolio (DPDPA / ISO 27701)

## Overview
This repository showcases a simulated end-to-end **Data Privacy & Governance Audit** conducted for a FinTech/E-Commerce application. Leveraging a Quality Assurance and System Validation mindset, this project demonstrates how regulatory frameworks (such as India's **DPDPA** and **ISO 27701**) are translated into operational controls, data maps, and risk assessments.

## Portfolio Artifacts
1. **Records of Processing Activities (ROPA) Inventory (`ROPA_Inventory.pdf`)**
   - Maps data assets, department owners, PII classifications, legal bases for processing, retention timelines, and technical security controls (AES-256 encryption at rest, SHA-256 salted hashing, RBAC).
2. **Data Subject Access Request (DSAR) SOP (`DSAR_Workflow_SOP.pdf`)**
   - Standard Operating Procedure detailing the end-to-end lifecycle of handling customer access and erasure ("Right to be Forgotten") requests—from identity verification and cross-database discovery to legal retention exceptions and audit logging.
3. **Privacy & Security Gap Assessment (`Privacy_Gap_Assessment.pdf`)**
   - Audit matrix evaluating application behavior against privacy controls (Consent Management, Privacy Notices, Data Minimization, Data Retention, and Vendor DPAs), categorizing risk levels and actionable remediations.

## Core Competencies Demonstrated
- PII Discovery & Data Lifecycle Mapping
- Privacy Gap Assessment & Risk Remediation
- DSAR & Consent Management Workflows
- Regulatory Alignment (DPDPA, GDPR, ISO 27701)
